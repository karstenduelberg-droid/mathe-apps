# Mathe-Apps

Kleine Browser-Apps für den Mathematikunterricht (Franz-Stock-Gymnasium Arnsberg).
Jede App ist eine einzelne HTML-Datei ohne externe Ressourcen; Eingaben bleiben im Browser des jeweiligen Geräts.

|---|---|
| Legeplan Potenzfunktionen (EF) | `legeplan-potenzfunktionen.html` |
