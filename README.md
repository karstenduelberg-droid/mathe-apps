# Mathe-Apps

Kleine Browser-Apps für den Mathematikunterricht (Franz-Stock-Gymnasium Arnsberg).
Jede App ist eine einzelne HTML-Datei ohne externe Ressourcen; Eingaben bleiben im Browser des jeweiligen Geräts.

| App | Datei |
|---|---|
| Legeplan Potenzfunktionen (EF) | `legeplan-potenzfunktionen.html` |
| Funktionsgraphen verschieben und strecken (EF, Kap. 1.3) – SuS-Fassung der Präsentation | `transformationen-ef.html` |
| Ganzrationale Funktionen: Begriff und Grad (EF, Kap. 1.4, Teil A) – SuS-Fassung der Präsentation | `ganzrationale-funktionen-ef.html` |
| Globalverlauf ganzrationaler Funktionen (EF, Kap. 1.4, Teil B) – SuS-Fassung der Präsentation | `globalverlauf-ef.html` |

Veröffentlicht über GitHub Pages: `https://karstenduelberg-droid.github.io/mathe-apps/`
